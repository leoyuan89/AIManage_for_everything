## 一、功能性缺失

### 1.1 PWA 同步到手机（MVP 6）
- **状态**：❌ 未实现
- **需求**：生成加密 HTML 快照，手机浏览器离线查看
- **当前情况**：UI 底部有"同步到手机"按钮，但无点击事件绑定，无具体实现
- **依赖文件**：`templates/pwa_template.html` 尚未创建

### 1.2 自动锁定与会话安全
- **状态**：❌ 未实现
- **需求**：
  - 5 分钟无鼠标/键盘操作自动锁定
  - 锁定遮罩界面，输入主密码解锁
- **当前情况**：
  - `on_lock()` 仅弹出确认框后关闭窗口
  - 无定时器检测用户空闲时间
  - 无锁定界面（LockScreen）组件

### 1.3 主题切换
- **状态**：⚠️ 部分实现
- **需求**：浅色/深色主题切换
- **当前情况**：
  - `qt-material` 库已在 `requirements.txt` 中
  - `main.py` 中 `use_qt_material = False` 被硬编码禁用
  - `settings_dialog.py` 中无主题切换选项

### 1.4 密保问题与密钥文件恢复
- **状态**：❌ 未实现
- **需求**：
  - 首次启动设置密保问题
  - 密钥文件（.key）用于密码恢复
- **当前情况**：
  - 数据库 `config` 表可存储配置，但无相关 UI 和逻辑
  - `config.json` 仅存储 salt 和版本

### 1.5 密码强度评估 UI 展示
- **状态**：⚠️ 部分实现
- **需求**：在账号详情中展示密码安全等级（强/中/弱）
- **当前情况**：
  - 数据库 `accounts` 表有 `security_level` 字段
  - `Account` 模型有该字段
  - 但 UI 中无展示位置，AI 评估 Prompt 未实际调用

### 1.6 AI 一句话备注展示
- **状态**：⚠️ 部分实现
- **需求**：AI 自动生成账号用途描述
- **当前情况**：

  - 但无生成逻辑，UI 中无展示

### 1.7 账号-网址深度关联
- **状态**：⚠️ 部分实现
- **需求**：同一平台下自动关联已存账号，查看密码时一键触达网址
- **当前情况**：
  - `urls` 表有 `related_account_id` 字段
  - 但主界面账号详情中未展示关联网址
  - 添加网址时无关联账号选择器

### 1.8 最近添加排序
- **状态**：⚠️ 部分实现
- **需求**：支持切换排序方式（首字母 / 最近添加）

## 二、已知 Bug / 代码问题

### 2.1 SettingsDialog 数据库连接引用错误
- **文件**：`ui/settings_dialog.py:277`
- **问题**：`self.db.connection.commit()` 应为 `self.db.conn.commit()`
- **影响**：修改主密码时可能抛出 AttributeError

### 2.2 MainWindow 搜索未使用 SearchService
- **文件**：`ui/main_window.py:on_search()`
- **问题**：当前搜索是简单的内存过滤，未调用 `SearchService.search()`，因此：
  - 拼音搜索不可用
  - 语义搜索不可用
  - 搜索结果无"精确匹配"/"AI推荐"标识区分

### 2.3 SemanticSearchService 与主界面未集成
- **文件**：`services/semantic_search_service.py`
- **问题**：向量索引构建和语义搜索功能已完整实现，但主界面从未调用
- **影响**：Embedding 向量搜索和"大模型增强搜索"开关当前无实际作用

### 2.4 DatabaseManager._migrate_database 返回值处理
- **文件**：`core/database.py:104-129`
- **问题**：迁移逻辑正确，但 `get_cached_category` 方法有重复 `return`（第 339-340 行）

## 三、性能与优化项

### 3.1 向量索引自动重建
- **需求**：AI 分类整理后，应自动重建语义向量索引
