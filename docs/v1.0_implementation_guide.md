## 一、项目概述

**本地密码保险箱** 是一款基于 PyQt6 的桌面密码管理软件，面向个人用户本地化、安全地管理账号密码和常用网址。软件核心特性包括：

- **端到端加密**：所有敏感字段（应用名、账号、密码、备注等）均使用 AES-256-GCM 加密存储，主密码遗忘则数据不可恢复。
- **本地 AI 集成**：基于 Ollama + Gemma4:4b 模型，提供智能分类、语义搜索、AI 备注生成、自然语言助手对话等功能。
- **双库管理**：独立的「密码库」（账号/密码）和「网址库」（常用链接），均支持二级分类体系。
- **离线 PWA 同步**：生成单文件 HTML 加密密包，手机浏览器打开即可离线查看全部数据，无需服务器。
- **回收站与快照**：软删除保留 30 天，AI 分类操作前自动创建快照，支持一键回滚。
- **批量导入/导出**：支持 Markdown、Excel、文本、浏览器收藏夹等多种格式的导入导出。

## 四、核心模块详解

### 4.1 加密引擎 (core/crypto.py)

采用 **PBKDF2-HMAC-SHA256 + AES-256-GCM** 方案：

- **密钥派生**：主密码通过 PBKDF2 派生 32 字节密钥，迭代次数 `100,000`，盐值 32 字节随机生成。
- **加密格式**：`nonce (12B) + ciphertext + tag (16B)`，使用 AESGCM 进行认证加密，防止篡改。
- **存储格式**：密文经 Base64 编码后存入 SQLite TEXT 字段。
- **跨设备恢复**：盐值随配置文件保存（`config.json`），加密备份文件第一行为盐值 Base64，第二行为加密数据。

```python
class CryptoManager:
    SALT_LENGTH = 32
    KEY_LENGTH = 32
    NONCE_LENGTH = 12
    ITERATIONS = 100000
```

### 4.2 数据库管理 (core/database.py)

SQLite 作为底层存储，通过 `DatabaseManager` 提供透明加解密：

- **自动加密**：`insert_account` / `update_account` 时，敏感字段自动调用 `_encrypt_field()`。
- **自动解密**：`get_account_by_id` / `get_all_accounts` 时，通过 `_decrypt_row()` 返回明文。
- **字段级加密策略**：`app_name`、`url`、`username`、`password`、`remark` 加密；`category`、`tags`、`security_level`、`ai_remark` 不加密（便于搜索和展示）。
- **数据库迁移**：`_migrate_database()` 自动检测并添加新字段（如 `tags`、`ai_remark`、`security_level`）。

**表结构**：

| 表名 | 用途 |
|------|------|
| `accounts` | 账号主表 |
| `category_cache` | AI 分类缓存（app_name_hash → category） |
| `config` | 键值配置 |
| `snapshots` | 分类快照（加密存储变更前状态和变更列表） |
| `audit_log` | AI 操作审计日志 |
| `recycle_bin` | 回收站（30 天过期） |
| `category_order` | 分类自定义排序 |

### 4.3 仓库模式 (core/repositories.py)

引入 **Repository Pattern** 统一密码库/网址库的数据访问接口：

- `VaultRepository`：抽象基类，定义查询、筛选、写操作、批量操作接口。
- `AccountRepository` / `URLRepository`：具体实现，面向 `Account` / `URLItem` 模型。
- `RepositoryFactory`：工厂单例，管理仓库实例生命周期，消除 `vault_type` 分支判断。

核心数据结构：
- `SearchResult`：统一搜索结果封装（items + matched_ids + query_description）。
- `PreviewRow` / `PreviewData`：AI 操作预览的标准化数据格式，UI 无关。
- `BatchItem`：批量导入中间格式，支持去重预检和分类校验。

### 4.4 分类体系 (core/category_utils.py)

全项目统一的分类路径工具，支持二级分类：

- **路径格式**：`主类>子类`，如 `编程学习与工具>代码托管`。
- **解析函数**：`parse_category_path()` 禁止三级及以上路径。
- **校验规则**：分类名禁止包含 `/`、`>`、`·` 以及首尾空白。
- **前缀匹配器**：`get_prefix_matcher()` 实现父节点匹配（选中「工作」匹配「工作」及「工作>开发工具」）。
- **树构建**：`build_category_tree()` 将扁平分类列表转为层级字典。

### 4.5 账号与网址模型 (models/)

`Account` 和 `URLItem` 均为 `@dataclass` 定义：

- **通用字段**：`id`, `category`, `tags` (JSON 字符串), `remark`, `ai_remark`, `created_at`, `updated_at`。
- **账号特有**：`app_name`, `url`, `username`, `password`, `security_level`, `last_password_change`。
- **网址特有**：`title`, `url`, `visit_count`, `related_account_id`。
- **标签管理**：`get_tags_list()` / `set_tags_list()` / `add_tag()` / `remove_tag()`。

## 五、AI 助手架构

### 5.1 AI 服务管理器 (services/ai_service_manager.py)

**单例模式**，全软件 AI 交互的唯一入口：

- **状态缓存**：`AIStateCache` 缓存 Ollama 状态（在线/离线/未知），查询毫秒级不阻塞 UI。
- **后台工作线程**：`AIWorkerThread` 独立线程轮询 Ollama 状态、处理任务队列。
- **信号驱动**：`state_changed` / `task_finished` / `task_failed` PyQt Signal 与 UI 解耦。
- **任务类型**：`CATEGORIZE`, `GENERATE_REMARK`, `CHAT`, `PARSE_COMMAND`, `SEMANTIC_SEARCH`, `CLASSIFY_BATCH`。

### 5.2 Ollama 客户端 (ai/ollama_client.py)

封装 Ollama `/api/generate` API：

- **上下文窗口**：`num_ctx = 32768`（32K），可承载约 500 条账号摘要。
- **JSON 鲁棒解析**：`_extract_json_object_robust()` 使用括号深度计数提取 JSON；`_fix_json()` 修复中文引号、未转义换行、末尾多余逗号等常见模型输出错误。
- **语义搜索**：`semantic_match()` 将查询词和条目摘要发送给模型，由模型基于语义理解判断相关性；失败时降级到本地关键词+拼音+同义词匹配。
- **智能分类**：`categorize()` 支持一级/二级分类模式，优先匹配已有分类。
- **Tool Calling**：`generate_tool_call()` 支持 ReAct 决策，返回结构化 `{"thought", "tool", "params", "target_categories"}`。

### 5.3 AI 助手服务 (services/ai_assistant_service.py)

自然语言指令解析与对话管理：

- **双模式设计**：
  - **Plan 模式**：只读操作（搜索、筛选、列出、解释），拦截所有写操作。
  - **Build 模式**：允许写操作（重组分类、添加备注、删除、批量添加），但需用户确认。
- **ReAct Agent**：`process_react_query()` 实现最多 5 轮 ReAct 循环（思考 → 调用工具 → 观察 → 再思考）。
- **指代消解**：通过 `ConversationContext` 和 `ReferenceResolver` 处理「这些」「刚才的」等代词。
- **局部操作识别**：`_filter_items_by_query()` 根据用户查询中的分类名和关键词，自动缩小操作范围。
- **流式输出**：`process_query_stream()` 支持打字机效果，token 批量节流（50ms/200字符）避免高频 Signal 崩溃。

### 5.4 AI 智能分类引擎 (services/ai_classification_service.py)

一键智能整理分类的工作流：

1. **预分析**（非阻塞）：AI 分析全部条目，提出 8-15 个分类提议（支持二级路径）。
2. **人工确认**：用户审核、修改、批准分类列表。
3. **执行归类**：分批处理（每批 10 条），AI 为每条分配最佳分类。
4. **差异预览**：展示变更前后的对比表格。
5. **生效/回滚**：确认后写入数据库，同时创建快照；可随时回滚。

降级策略：Ollama 不可用时，使用本地关键词启发式分类。

### 5.5 AI 工具注册表 (services/ai_tools.py)

基于权限等级的工具系统：

- **PermissionLevel**：`READONLY`（直接返回）、`PREVIEW`（需确认预览）、`CONFIRM`（需确认执行）。
- **ToolRegistry**：全局注册表，支持 `semantic_search_accounts`、`batch_update_accounts`、`smart_classify_accounts` 等工具。
- **参数校验**：每把工具自带 `params_schema`，执行前自动校验。

## 七、数据安全设计

### 7.1 加密策略

- **敏感字段全加密**：应用名、账号、密码、网址、用户备注使用 AES-256-GCM 加密。
- **分类/标签不加密**：便于 SQL 查询、分类筛选、AI 分析。
- **主密码不存储**：仅保存盐值，密码验证通过「尝试解密」实现。

### 7.2 登录验证流程

1. 首次启动：用户设置主密码 → 生成盐值 → 创建数据库。
2. 非首次启动：输入主密码 → 用盐值派生密钥 → 尝试解密数据库第一条记录 → 成功则进入，失败则提示重试。
3. 密码遗忘 = 数据不可恢复（设计如此）。

### 7.3 剪贴板安全 (core/clipboard.py)

- **密码复制后 20 秒自动清空**：仅当剪贴板内容未被用户修改时才清空。
- **独立线程定时器**：`threading.Timer` 实现，不阻塞 UI。

### 7.4 密码强度评估 (core/password_strength.py)

本地规则评分，无需联网：

| 评分 | 条件 | 标签 |
|------|------|------|
| 4 | ≥16 字符 + 4 种字符类型 | 极强 |
| 3 | ≥12 字符 + 3 种字符类型 | 强 |
| 2 | ≥8 字符 + 2 种字符类型 | 中 |
| 0-1 | 其他 | 弱 |

## 八、移动端 PWA 同步

### 8.1 同步服务 (services/sync_service.py)

生成单文件 HTML 密包：

1. **序列化数据**：将账号和网址列表转为 JSON，预计算拼音首字母排序字段（`_alpha_key`, `_sort_key`）。
2. **加密**：使用主密码派生的密钥加密 JSON 数据。
3. **注入模板**：读取 `templates/pwa_template.html`，将 `{{ENCRYPTED_DATA}}`、`{{SALT_BASE64}}` 等占位符替换为真实值。
4. **输出**：单个 `.html` 文件，可通过任何方式传输到手机。

### 8.2 PWA 模板 (templates/pwa_template.html)

纯前端单页应用，无外部依赖：

- **解锁**：用户输入主密码 → JS 端 PBKDF2 + AES-GCM 解密 → 纯内存中渲染。
- **页面栈导航**：`pushScreen()` / `popScreen()` 实现 iOS 风格页面推入/弹出，支持手势侧滑返回。
- **分类展示**：二级分类网格 → 子分类列表 → 条目列表 → 详情页。
- **搜索**：实时过滤，支持按「全部/密码/网址」筛选。
- **安全**：关闭页面后数据自动清除，不残留本地存储。
- **测试模式**：当占位符未被替换时（`ENCRYPTED_DATA.startsWith('{{')`），输入 `test` 可进入测试模式，加载模拟数据。

## 九、导入与导出

### 9.1 导入服务 (services/import_service.py)

支持多格式解析：

- **Markdown**：表格格式（`|` 分隔）和段落格式（`##` 标题分割）。
- **Excel**：自动识别表头（支持中英文别名映射）。
- **文本**：等号/冒号分隔键值对，或按行推断字段顺序。
- **浏览器收藏夹**：解析 Netscape Bookmark HTML，`<H3>` 文件夹递归为二级分类，三级及以上截断。

字段名映射（`FIELD_MAPPING`）：支持中英文、大小写、别名混用。

### 9.2 导出服务 (services/export_service.py)

- **Excel 导出**：账号和网址分别导出，含样式、边框、冻结首行。
- **加密备份**：`.vault` 格式，盐值+加密数据两行存储，支持跨设备恢复。
- **HTML 书签**：按二级分类嵌套生成 `<H3>` 文件夹，可被 Chrome/Edge/Firefox 直接导入。

## 十、批量导入处理器 (services/batch_add_processor.py)

- **智能分块**：按 4000 字符/20 条上限将长文本切割为多个 chunk。
- **AI 解析**：每个 chunk 调用 Ollama 提取结构化 JSON 数组。
- **预检机制**：
  - 必填字段检查（账号需 app+account，网址需 title+url）。
  - 重复检查（基于应用名+账号或网址精确匹配）。
  - 分类校验（截断三级及以上，校验非法字符）。
- **预览确认**：`BatchAddPreviewWidget` 展示解析结果，用户可勾选/编辑后执行导入。

## 十二、关键设计决策

| 决策 | 说明 |
|------|------|
| SQLite 而非 SQLCipher | 避免 Windows 平台 C 扩展编译问题，应用层加密足够安全 |
| 分类不加密 | 牺牲极小安全性换取 SQL 查询性能和 AI 分析便利 |
| Ollama 本地部署 | 数据不上云，保护隐私；gemma4:4b 在 8G 显存可流畅运行 |
| 单文件 HTML 密包 | 不依赖服务器和 App Store，任意手机浏览器即可打开 |
| ReAct Agent | 将大模型决策与工具执行分离，Plan/Build 双模式保障安全 |
| Repository Pattern | 统一密码库/网址库抽象，AI 助手无需判断 vault_type |
