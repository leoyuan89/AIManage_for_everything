## 1. 功能概述

支持从多种格式文件批量导入账号数据，解决用户已有账号数据迁移问题。

## 2. 支持格式

### 2.1 Markdown (.md)

**示例格式**：
```markdown
# 账号清单

## 支付宝
- 账号: 138****1234
- 密码: mypassword
- 网址: https://www.alipay.com
- 分类: 金融
- 备注: 绑定了银行卡

## 微信
- 账号: wx_user_001
- 密码: wx_pass_789
- 网址: https://weixin.qq.com
- 分类: 社交
```

**解析规则**：
- `## 标题` → 应用名
- `- 账号/用户名/Account:` → 账号
- `- 密码/Password:` → 密码
- `- 网址/URL:` → 网址
- `- 分类/Category:` → 分类
- `- 备注/Remark:` → 备注

### 2.2 文本文件 (.txt)

**示例格式**（支持多种分隔符）：

**格式 A：等号分隔**
```
应用名=支付宝
账号=138****1234
密码=mypassword
网址=https://www.alipay.com
分类=金融

应用名=微信
账号=wx_user_001
密码=wx_pass_789
分类=社交
```

**格式 B：冒号分隔**
```
应用名: 支付宝
账号: 138****1234
密码: mypassword

应用名: 微信
账号: wx_user_001
密码: wx_pass_789
```

**格式 C：空行分隔的段落**
```
支付宝
138****1234
mypassword
https://www.alipay.com
金融

微信
wx_user_001
wx_pass_789
社交
```

### 2.3 Excel (.xlsx)

**表头要求**（不区分大小写，支持中文/英文）：

| 应用名/App | 账号/Username | 密码/Password | 网址/URL | 分类/Category | 备注/Remark |
|-----------|--------------|--------------|---------|--------------|------------|
| 支付宝 | 138****1234 | mypassword | https://alipay.com | 金融 | 绑定银行卡 |
| 微信 | wx_user_001 | wx_pass_789 | https://weixin.qq.com | 社交 | 工作号 |

**支持的列名映射**：
- 应用名：`应用名`, `app_name`, `App`, `应用`, `名称`, `Name`
- 账号：`账号`, `username`, `用户名`, `Account`, `User`, `登录名`
- 密码：`密码`, `password`, `口令`, `Password`, `Pass`, `Pwd`
- 网址：`网址`, `url`, `URL`, `网站`, `链接`, `Link`
- 分类：`分类`, `category`, `类别`, `Category`, `类型`, `Type`
- 备注：`备注`, `remark`, `说明`, `Remark`, `描述`, `Description`

## 3. 导入流程

```
用户点击"批量导入"
    ↓
选择文件（.md / .txt / .xlsx）
    ↓
系统自动检测文件格式
    ↓
解析文件内容
    ↓
显示导入预览（表格形式）
    ↓
用户确认/编辑/删除行
    ↓
批量插入数据库（加密存储）
    ↓
显示导入结果（成功/失败统计）
```

## 5. 冲突处理

| 场景 | 处理方式 |
|------|---------|
| 应用名+账号完全重复 | 提示"已存在，跳过"或"覆盖" |
| 必填字段缺失（应用名/账号/密码） | 标红提示，不允许导入该行 |
| 分类不存在 | 自动归类为"其他"或提示用户选择 |
| Excel 列名不匹配 | 尝试智能匹配，失败则提示用户手动映射 |

## 6. 安全考虑

- 导入过程中密码明文仅在内存中，写入前立即加密
- 导入完成后不保留原始文件内容
- 支持导入时选择"导入后删除源文件"（可选）
