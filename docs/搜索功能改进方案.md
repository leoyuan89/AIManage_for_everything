# 搜索功能改进方案

## 1. 问题诊断

### 1.1 密码库搜索（当前）

当前 `SearchService._exact_match()` 搜索的字段及权重：

| 字段 | 权重 | 状态 |
|------|------|------|
| app_name（应用名） | 1.0 | ✅ 已有 |
| username（账号） | 0.9 | ✅ 已有 |
| url（网址） | 0.8 | ✅ 已有 |
| tags（标签） | 0.75 | ✅ 已有 |
| remark（用户备注） | 0.7 | ✅ 已有 |
| category（分类） | 0.6 | ✅ 已有 |
| **ai_remark（AI备注）** | — | ❌ **缺失** |

当前 `SearchService._pinyin_match()` 搜索的字段：

| 字段 | 状态 |
|------|------|
| app_name（应用名） | ✅ 已有 |
| category（分类） | ✅ 已有 |
| **remark（用户备注）** | ❌ **缺失** |
| **ai_remark（AI备注）** | ❌ **缺失** |

### 1.2 网址库搜索（当前）

当前 `URLDatabaseManager.search_urls()` 的 SQL 查询：

```sql
SELECT * FROM urls
WHERE title LIKE ? OR url LIKE ? OR tags LIKE ?
ORDER BY created_at DESC
```

搜索了 `title`、`url`、`tags` 三个字段。

| 字段 | 状态 |
|------|------|
| title（标题） | ✅ 已有 |
| url（网址） | ✅ 已有 |
| tags（标签） | ✅ 已有 |
| **ai_remark（AI备注）** | ❌ **缺失** |
| **remark（用户备注）** | ❌ **缺失** |

---

## 2. 改进目标

- **密码库搜索范围**：应用名、网址、AI备注、用户备注（也保留已有的 username、category、tags）
- **网址库搜索范围**：标题、网址、AI备注、用户备注（也保留已有的 tags）

---

## 3. 改进方案

### 3.1 密码库搜索改进

**文件**：`services/search_service.py`

#### 3.1.1 `_exact_match()` — 增加 ai_remark 精确匹配

在 `remark` 匹配之后、`category` 匹配之前，插入 `ai_remark` 匹配：

```python
# AI备注匹配
if account.ai_remark and query in account.ai_remark.lower():
    return ('ai_remark', 0.75)
```

权重 0.75，与 tags 同级，因为 ai_remark 的命中率与标签相近，比用户备注略高。

#### 3.1.2 `_pinyin_match()` — 增加 remark 和 ai_remark 拼音匹配

在现有 `app_name` 和 `category` 之后追加：

```python
# 用户备注拼音匹配
if account.remark and PinyinConverter.match_pinyin(query, account.remark):
    return ('remark', 0.65)

# AI备注拼音匹配
if account.ai_remark and PinyinConverter.match_pinyin(query, account.ai_remark):
    return ('ai_remark', 0.65)
```

权重 0.65，低于 category 的 0.7，因为备注内容较长，拼音匹配的精确度较低。

### 3.2 网址库搜索改进

**文件**：`core/url_database.py`

#### 3.2.1 `search_urls()` — 扩展 SQL 查询字段

将搜索 SQL 从：

```sql
WHERE title LIKE ? OR url LIKE ? OR tags LIKE ?
```

改为：

```sql
WHERE title LIKE ? OR url LIKE ? OR tags LIKE ? OR ai_remark LIKE ? OR remark LIKE ?
```

对应参数从 `(keyword, keyword, keyword)` 改为 `(keyword, keyword, keyword, keyword, keyword)`。

### 3.3 UI 搜索框提示文本更新

**文件**：`ui/main_window.py`

当前提示文本：
- 密码库：`"搜索账号（支持拼音，如：wx=微信），按回车搜索..."`
- 网址库：`"搜索网址..."`

改进后：
- 密码库：`"搜索账号（应用名/网址/备注），按回车搜索..."`
- 网址库：`"搜索网址（标题/网址/备注），按回车搜索..."`
